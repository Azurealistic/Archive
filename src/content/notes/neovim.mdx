I use [LazyVim](https://www.lazyvim.org/) and my config is hosted on [GitHub](https://github.com/Azurealistic/Vim).

Non-LazyVim plugins: [neoscroll](https://github.com/karb94/neoscroll.nvim), [rustaceanvim](https://github.com/mrcjkb/rustaceanvim/) and [projectionist](https://github.com/tpope/vim-projectionist).

- Neoscroll animates `<C-d>`, `<C-u>` and other commands allowing the view glides instead of jumping and you can follow where the cursor lands.
- Rustaceanvim uses the existing `rust-analyzer` rather than requiring installation of another LSP.
- Projectionist maps a source file to its test, so `:A` flips between the two.
